# Cyberhelp LLC Travel Pay Package Calculator v1.0

Web calculator for Cyberhelp LLC recruiters to check margin on travel nurse pay packages before making an offer.

## Rules built in
| Setting | Value |
|---|---|
| Payroll load | **9.5% on W2 only** (RT + OT + W2 bonus/reimbursement; not on per diem) – locked |
| Onboarding (OB) cost | **$300** per new placement (not charged on extensions) |
| MSP/VMS fee | **0%** – locked |
| NBO (non-billable orientation) | **0 hrs** – locked; clicking it asks "Usually the NBO is zero for state clients. Do you still want to add NBO hours?" and unlocks only on Yes |
| Desired GP / net margin | **18%** of revenue |
| Client OT | "Client bills OT? = No" bills every hour at straight time |

## Use it online
`https://prashanttyagi3112.github.io/cyberhelp-calculator/`

Nothing typed into the calculator is saved or sent anywhere – all math runs in the browser.
